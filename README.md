# آزمون‌ساز
ساختار: کتاب ← آزمون ← سوال و پاسخ.

- معلم: پنل معلم ← افزودن کتاب ← ورود به کتاب ← افزودن/ویرایش/ارسال آزمون.
  - «ارسال» یک **لینک آماده** (`azmoon://exam?d=...`) می‌سازد که کل آزمون در آن است.
  - در ویرایشگر، پیش‌نمایش جفت «سوال ↔ پاسخ» و تاریخ بارگذاری هر سوال دیده می‌شود. جفت‌شدن بر اساس شماره است.
  - پشتیبان‌گیری/بازیابی: پنل معلم ← «گرفتن پشتیبان» / «بازیابی».
  - حذف کتاب یا آزمون همیشه تأیید می‌گیرد.
- دانش‌آموز: دریافت آزمون ← لینک را بچسباند (یا روی لینک بزند) ← ذخیره ← کتاب ← آزمون ← تعداد سوال ← شروع.
  - کمتر از ۵۰ سوال انتخاب شود: سوال‌ها تصادفی پرسیده می‌شوند.
  - بعد از «پاسخ»، دو دکمهٔ «✅ صحیح گفتم» و «❌ اشتباه گفتم» باز می‌شود؛ در پایان تعداد «صحیح گفتم» نمایش داده می‌شود.
- ساخت APK: GitHub Actions. امضای ثابت (app/debug.keystore) باعث می‌شود نسخهٔ جدید روی قبلی نصب شود.
